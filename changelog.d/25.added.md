Added four submission artifact types to `apex.competition.v1`: `json` and `csv` for closed-grammar
data submissions, `wasm` for computation with no ambient authority, and `archive` for tarball/zip
bundles of multiple files (e.g. a multi-module Python package) extracted into `target_path`.
`archive` carries a `submission.archive` block bounding extraction (`format`, `entry_file`,
`max_uncompressed_mb`, `max_files`), and `screening` gained Layer-1 knobs for the new types.
`apex-dev preflight --submission` (and `apex-dev run`) now check a local artifact against the
declared type — parse validity, wasm magic bytes, archive member safety and extraction bounds,
size ceilings — and report advisories for screening knobs that don't apply to it.
